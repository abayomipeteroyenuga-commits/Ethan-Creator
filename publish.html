Publish your Ethan Creator website

Website Studio exports a static website ZIP. Downloading the ZIP does not publish the site or reserve a domain.

1. Export

Open Website Studio, customise your content and select Download website ZIP.

2. Extract

Unzip the downloaded file. It contains an index.html page with your design and optional embedded hero image.

3. Host

Upload the extracted index.html to a static hosting provider or GitHub repository and deploy it using your hosting provider's instructions.

4. Connect a domain

If you own a domain, configure it in your hosting provider and update DNS at your domain registrar.

Contact buttons can open an email application. The exported site does not include a backend, accounts, payment checkout, or server-side forms.
